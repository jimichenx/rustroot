## 我们要解决的问题

到这里用的都是现成的类型。现在要自己造一个：一个用户有名字和年龄，把这两个值捆在一起，当成一个值传来传去。

4.2 说过，编译器判断复制还是移动，查的是类型的规矩。标准库的类型，规矩是写好的。你自己捆出来的类型，规矩从哪来？

## 字段同时存在

捆在一起的类型叫结构体（Struct），里面的每个值叫一个字段（Field）。一个 `User` 同时有 `name` 和 `age`。

可能的取值数，是每个字段可能的取值数相乘，所以结构体也叫乘积类型（Product Type）。

## 移走一个字段

`let name = user.name` 把名字字段移给一个新绑定。移走之后，`user` 还能用吗？

**第一版：整个 `user` 失效。** 可 `age` 是整数，一个字节也没动，所有者也没变。让它跟着失效，没有规则要求这样做。

**第二版：只让被移走的那个字段失效。** 4.1 说，编译器在每一行都知道一个名字此刻有没有值。把这个跟踪细到字段：`user.name` 没有值了，`user.age` 还有。

`user.age` 照常能用。取消最后一行的注释，报 `error[E0382]`：`user.name` 已经被移走。这叫部分移动（Partial Move）。这时 `user` 不能再整个拿去用，因为它缺了一个字段。

## 能不能复制，谁说了算

`Point` 只有两个 `i32`。它的规矩从哪来？

### 第一版：编译器按字段推断

字段全能复制，整体就复制；有一个字段带释放责任，整体就移动。这是把切割线自动套在字段上，看起来顺理成章。

**撞墙一：加一个字段，悄悄改了别人的代码。** 某天类型的作者给 `Point` 加了一个 `label: String`。在他看来只是多了一个字段。可按第一版，`Point` 从复制变成了移动，所有用到 `Point` 的地方，原来 `let b = a` 之后还能用 `a` 的代码，现在全部编译不过。规矩变了，却没有写在任何地方。

**撞墙二：全是整数，却代表唯一的东西。** 一个售票系统里，`Seat { row: u32, col: u32 }` 代表一个已经卖出的座位。按第一版，它能复制。复制一份，同一个座位就卖给了两个人。4.2 的 `File` 也只有一个整数：字节里没有释放责任，只是能复制的必要条件。一个类型该不该复制，只有写它的人知道。

### 第二版：由类型作者声明

能复制，要作者明写出来。不写，就移动。

默认选移动，是因为移动总是安全的：一个值只有一个所有者，不会出第二个。复制要有人担保「多一份也没关系」。

作者写了，编译器还要查必要条件：有一个字段带着释放责任，这个声明就不成立。

| :--- | :--- | :--- |
| 全部能复制 | 移动 | 复制 |
| 有一个带释放责任 | 移动 | `error[E0204]` |

## 约定也要守住

4.2 里，`String` 比 `Vec<u8>` 多一条约定：字节必须是 UTF-8。你自己的类型也会有约定。比如 `Even`，里面的数永远是偶数。这种任何时候都成立的约定，叫不变量（Invariant）。

**第一版：写在注释里。** 「请只放偶数。」任何人都能写 `Even { value: 3 }`，编译器不拦。

**第二版：只留一个入口。** 所有 `Even` 都从一个函数造出来，函数只造偶数。要做到这一点，模块外的代码就不能直接写字段，也不能读了再改。

<Code code={privateField} lang="rust" />

`Even` 在模块 `parity` 里，字段 `value` 没有写 `pub`。模块外的 `main` 读不到它，也写不出 `Even { value: 3 }`：取消最后一行的注释，报 `error[E0451]`，字段是私有的。模块外拿到 `Even` 的唯一途径是 `parity::double`，它只存偶数。

Rust 的字段默认私有。不变量在模块里建立一次，模块外只能经过模块给的入口。这种入口通常写成方法的形式，叫构造函数，5.3 讲。

## 字段存一个引用

字段能存 `&str` 吗？结构体若借着别人的文本，它就活不过那段文本。这个限制要写进结构体的类型里，否则编译器没法在用到它的地方核对 1.5 的规则。

<Aside type="tip" title="如果你来自 Java">
  Java 类的字段都是引用，写 `String name` 就行，对象能不能复制由有没有 `clone` 方法决定，赋值总是共享。Rust 的 `name: String` 表示结构体拥有这段文本，`name: &str` 表示借着别人的。能不能复制，看作者有没有声明 `Copy`。
</Aside>

## 顿悟时刻

结构体的移动按字段算，编译器跟踪到每一个字段。

能不能复制，是类型的规矩，由写类型的人声明。编译器不替你推断，因为布局只是必要条件，而且推断出来的规矩会在你加字段时悄悄改变。不声明就移动，声明了编译器查必要条件。

约定写在注释里守不住，要靠私有字段，把建立值的入口收到模块里。
