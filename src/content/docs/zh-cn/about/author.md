我是 **jimichen**，从事算法研发与系统架构工作。

写了多年其他语言后，我开始用 Rust 做项目。最难的一步，是从原有的编程习惯转过来，建立起 Rust 的思维方式。

从那时起，我一直在找一条线索，试着把这套思维方式从头理顺，希望能减少从其他语言跨过来时的摩擦，让学习曲线更平缓一些。Rust Root 是我顺着这个想法写下的一次尝试。
