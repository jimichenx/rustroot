<p class="rr-home-eyebrow">为什么旧经验会失灵</p>
<h2 id="shifts-title">跨不过去的往往不是语法，而是既有习惯</h2>
<p>许多有经验的开发者并非记不住所有权规则，而是在用旧语言的隐式模型组织代码。把思考的出发点切换过来，编译器的检查就会从阻力变成帮手。</p>

<div class="rr-home-shifts">
<article class="rr-home-shift">
<div class="rr-home-shift-dim">内存与状态</div>
<div class="rr-home-shift-from">
<span class="rr-home-shift-tag">过往语言习惯</span>
<p>默认万物皆引用，由运行时在后台回收内存，对象可在多处共享并随时修改。</p>
</div>
<span class="rr-home-shift-arrow" aria-hidden="true">→</span>
<div class="rr-home-shift-to">
<span class="rr-home-shift-tag">Rust 原生视角</span>
<p>栈帧与堆块责任分明，同一时刻只有一个所有者，共享只读与独占可变在编译期显式排他。</p>
</div>
</article>

<article class="rr-home-shift">
<div class="rr-home-shift-dim">数据与错误</div>
<div class="rr-home-shift-from">
<span class="rr-home-shift-tag">过往语言习惯</span>
<p>习惯用类继承表达分支变体，空值（<code>null</code>）与隐式异常可能混入任意一条调用链。</p>
</div>
<span class="rr-home-shift-arrow" aria-hidden="true">→</span>
<div class="rr-home-shift-to">
<span class="rr-home-shift-tag">Rust 原生视角</span>
<p>用 <code>struct</code> 与闭合 <code>enum</code> 组合数据形状，把缺失（<code>Option</code>）与失败（<code>Result</code>）编码进返回类型。</p>
</div>
</article>

<article class="rr-home-shift">
<div class="rr-home-shift-dim">抽象与成本</div>
<div class="rr-home-shift-from">
<span class="rr-home-shift-tag">过往语言习惯</span>
<p>依赖接口虚表与运行时反射换取灵活度，内存分配与并发竞争留到运行期承担。</p>
</div>
<span class="rr-home-shift-arrow" aria-hidden="true">→</span>
<div class="rr-home-shift-to">
<span class="rr-home-shift-tag">Rust 原生视角</span>
<p>默认采用编译期单态化与语法树宏展开，仅在跨过静态边界时按需启用 <code>dyn Trait</code> 或引用计数。</p>
</div>
</article>
</div>

<section class="rr-home-section" aria-labelledby="outcomes-title">
<p class="rr-home-eyebrow">你将获得什么</p>
<h2 id="outcomes-title">从看懂编译检查，到掌握工程裁决</h2>
<p>用内存事实、可运行的代码实验与跨语言视角对照，把思考方法直接迁移到真实项目开发中。</p>

<div class="rr-home-outcomes">
<article class="rr-home-outcome">
<span class="rr-home-outcome-number">01</span>
<h3>转换思维视角</h3>
<p>看清旧语言的隐式习惯为何在 Rust 中失效，从内存责任与数据流出发建立原生直觉，不再与编译器反复拉锯。</p>
</article>
<article class="rr-home-outcome">
<span class="rr-home-outcome-number">02</span>
<h3>贯通核心机制</h3>
<p>把所有权、代数数据类型（<code>struct</code> / <code>enum</code>）、Trait 分发、智能指针与异步并发连成一套前后咬合的体系，而非孤立的语法碎片。</p>
</article>
<article class="rr-home-outcome">
<span class="rr-home-outcome-number">03</span>
<h3>掌握工程裁决</h3>
<p>在真实业务与 AI 辅助编码中，懂得如何用类型签名守住安全边界，识别并消除无谓的 <code>.clone()</code>、锁竞争与过度抽象。</p>
</article>
</div>
</section>
